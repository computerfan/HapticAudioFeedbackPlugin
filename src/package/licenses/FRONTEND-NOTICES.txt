Pico is distributed as precompiled CSS with its embedded SVG control icons.
It has no runtime dependencies. Its npm build tools are not redistributed.
All frontend assets are bundled locally; no CDN or web fonts are requested.

The frontend JavaScript uses browser-provided DOM, Fetch, session storage,
BigInt, and Canvas 2D APIs. No JavaScript library, polyfill, or browser runtime
is redistributed. Text uses installed system fonts and Unicode characters.

Native and managed audio components are separate from the browser frontend.
Their notices are in CPAL-NOTICES.txt and NAudio-MIT.txt in this directory.
